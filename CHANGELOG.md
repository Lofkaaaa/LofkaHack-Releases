# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [0.5.0] - 2026-10-26

### Добавлено
- **Мод-меню с 5 вкладками:**
  - Основные: Noclip, Safe Mode, Practice Music Sync, Jump Hack, Instant Complete, Auto Kill, Respawn Time
  - Speedhack: множитель скорости 0.1x-10x с опциональным влиянием на музыку
  - Косметика: 11 функций (No Glow, No Pulse, No Shake, Solid Wave Trail и др.)
  - Статистика: FPS, CPS, Attempts в реальном времени (4 угла экрана)
  - Прочее: настройки языка, персонализация UI

- **Установщик и патчер:**
  - Автоматическое определение папки Geometry Dash
  - Совместимость с MegaHack v9 (Tab) и другими модами
  - Система версий с пометкой "New!"
  - Проверка наличия файлов мода для активации кнопок

- **Защита авторских прав:**
  - Лицензионное соглашение (EULA) при установке
  - Проверка целостности файлов (SHA-256)
  - Метаданные в PE-файлах (Company: Lofkaaaa, Copyright: © 2026)
  - Водяные знаки в DLL (LOFKAHACK_SIGNATURE)

- **Система обновлений:**
  - Автоматическая проверка обновлений при запуске патчера
  - Ручная проверка через меню "Проверить обновления"
  - Интеграция с GitHub Releases API
  - Скачивание обновлений во временную папку

- **Персонализация UI:**
  - 5 цветовых пресетов (Blue, Crimson, Violet, Emerald, Graphite)
  - 3 стиля дизайна (Glass, Neon, Brutal)
  - Настройка скругления, границ, плотности
  - 6 шрифтов (включая встроенный Monocraft)
  - Анимации открытия окна и переключения вкладок

### Технические детали
- **Архитектура:** C++17, Win32 API, Dear ImGui
- **Компиляция:** MinGW-w64 (cross-compile) или MSVC
- **Зависимости:** MinHook, Dear ImGui, OpenGL32, GDI32, User32, WinHTTP
- **ABI версия:** 6 (для совместимости с плагинами)

### Известные проблемы
- Кнопка dropbox не работает (временно используется текстовая метка "[RMB]")
- При перемещении ползунков игра может подвисать (решено: конфиг сохраняется при закрытии меню)

### Безопасность
- Ни одного патча .text в GeometryDash.exe
- Только атомарная подмена слотов .rdata VTable и адресов PE IAT
- Совместимость с 14-байтовыми хуками MegaHack v9
