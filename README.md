## 🎮 О проекте

LofkaHack — это нативное C++17 мод-меню для Geometry Dash с современным интерфейсом на Dear ImGui. Включает строгий системный установщик, патчер с автоопределением папки игры, прокси-загрузчик `XInput1_4.dll` (совместимый с MegaHack v9 на `Tab`) и внутриигровое мод-меню на клавишу `Insert`.

---

## ✨ Возможности

### Внутриигровое мод-меню (INSERT)
- **5 вкладок:** Основные, Speedhack, Косметика, Статистика, Прочее
- **Noclip** с защитой Player 1/2 и живой телеметрией
- **Safe Mode** (ручной и автоматический)
- **Speedhack** (0.1x — 10x) с опциональным влиянием на музыку
- **11 косметических функций:** No Glow, No Pulse, No Shake, Solid Wave Trail и др.
- **Статистика:** FPS, CPS, Attempts в реальном времени
- **Персонализация:** темы, цвета, шрифты, анимации

### Установщик и патчер
- Автоматическое определение папки Geometry Dash (Steam Registry, libraryfolders.vdf, запущенный процесс)
- Совместимость с MegaHack v9 (Tab) и другими модами
- Система обновлений через GitHub Releases
- Проверка целостности файлов (SHA-256)
- Лицензионное соглашение (EULA)

## 🚀 Установка

### Вариант 1: Автоматическая установка (рекомендуется)

1. Скачайте `LofkaHack_Setup.exe` из [последнего релиза](https://github.com/Lofkaaaa/LofkaHack-Releases/releases/latest)
2. Запустите установщик
3. Примите лицензионное соглашение
4. Выберите папку Geometry Dash (обычно определяется автоматически)
5. Нажмите "Установить"

### Вариант 2: Ручная установка

1. Скачайте `LofkaHack_Patcher.exe`
2. Запустите патчер
3. Укажите путь к папке Geometry Dash
4. Нажмите "Установить"

---

## 🎯 Использование

1. Запустите Geometry Dash
2. Нажмите **INSERT** для открытия мод-меню
3. Настройте функции по вашему вкусу
4. Нажмите **TAB** для MegaHack (если установлен)

Патчер автоматически проверяет наличие обновлений при запуске. Вы также можете проверить обновления вручную:
